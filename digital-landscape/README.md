# @Pets — Standalone Digital Landscape

This repository is the independent home for the user's digital ChatGPT pets and the creative environment they inhabit.

## Keep it separate
- **Not a coding target for NEXUS automated software improvement.**
- **Not Movie Assistant, MediaBridge, or PC Remote.**
- Do not copy this repository into program-building folders or send private pet art into public code analysis.
- Do not run automated refactoring of characters, sprites, sound, or creative prompts without an explicit pet-specific request.

## Seven daily slots
The public repository contains a **browser rotation prototype**, not installed pets. It uses placeholders rather than the real character assets.
- Confirmed in private asset index: Astryx, Bramble, Bramble-Cosmic, Stardust.
- Not verified as installed here: Aurelon, Mochi, Nexus.
- Keep a fair seven-slot daily rotation and bench swapping after more than seven real characters are approved.
- Test animation and actual platform behavior before describing any character as live.

## Layout and independent release workflow
Keep pet assets in an explicitly approved, private location with permission checks. Public placeholders and rotation tests may stay here. For any future installed pet: verify its asset manifest, movement, reduced-motion settings, persistence, and actual runtime before publishing.

The existing root-level prototype files are intentionally preserved. This document makes a separate **digital-landscape/** area discoverable without moving or deleting any assets.
